03 // THE CLINICAL & MARKET PROBLEM

ทำไม ภาวะคอยื่น (Forward Head Posture) ถึงเป็นวิกฤตของคนทำงานยุคดิจิทัล?

เมื่อเราจ้องหน้าจอคอมพิวเตอร์เป็นเวลานาน ร่างกายจะยื่นศีรษะไปข้างหน้าโดยไม่รู้ตัว (Protraction) ทุกๆ 1 นิ้วที่ศีรษะยื่นล้ำแนวกระดูก C7 ออกไป น้ำหนักที่กดทับหมอนรองกระดูกคอจะเพิ่มขึ้นเป็นทวีคูณ (งานวิจัยของ Dr. Kenneth Hansraj, 2014)

กระดูกคอส่วนล่าง (C5–C7) รับแรงอัดสูงผิดปกติ เสี่ยงต่อภาวะหมอนรองกระดูกทับเส้นประสาท (Cervical Radiculopathy)

⚠️ ข้อจำกัดของอุปกรณ์เตือนท่าทางที่มีอยู่ในท้องตลาดปัจจุบัน (Why Existing Products Fail)

1. แผ่นแปะหลังตัวเดียว (Single Back Sensor): วัดได้เฉพาะเวลา "หลังค่อม" แต่ตรวจจับเวลาผู้ใช้นั่งพิงพนักเก้าอี้แล้วยื่นเฉพาะคอไปหาจอคอมพิวเตอร์ไม่ได้
2. หูฟังตรวจจับท่าทางทั่วไป (Earbuds Only): เวลาคนยื่นคอจ้องจอคอมฯ ศีรษะจะแหงนขึ้นเพื่อรักษาระดับสายตาให้ขนานพื้น (Head Pitch ≈ 0°) เซ็นเซอร์ที่หูอย่างเดียวจึงนึกว่านั่งตัวตรง!
3. ปัญหา IMU Drift เมื่อใส่ต่อเนื่อง: อุปกรณ์ทั่วไปไม่มีจุดอ้างอิง Origin ร่วมระหว่างฐานคอ C7 กับใบหูซ้าย-ขวา ทำให้เกิดค่าเพี้ยนสะสม (Drift) และแจ้งเตือนผิดพลาดหลังจากใช้งานไปเพียง 15–30 นาที

ด้วยการเปรียบเทียบเวกเตอร์พิกัดระหว่างใบหูกับจุดกำเนิด Origin ที่โหนด C7 ระบบสามารถแยกแยะได้ทันทีว่าผู้ใช้กำลัง ยื่นคอจ้องจอคอมพิวเตอร์ (FHP) หรือ ก้มหน้าอ่านเอกสาร (Neck Flexion)

05 // ORIGIN-REFERENCED CALIBRATION & DRIFT CORRECTION

อัลกอริทึมการแก้ปัญหา Diff / Drift ด้วยการเช็ค Origin Location ($O_{\text{origin}}$)

3-STAGE ORIGIN CALIBRATION & DRIFT COMPENSATION

1. การล็อกพิกัดเริ่มต้นเป็นจุดอ้างอิง (Origin Location Capture @ t=0)

เมื่อเริ่มการทดสอบ ระบบกำหนดให้กระดูก C7 เป็นจุดกำเนิดพิกัด O_C7 = (0,0,0) และบันทึก Quaternion เริ่มต้นของทั้ง 3 โหนด ($\mathbf{q}_{L,0}, \mathbf{q}_{R,0}, \mathbf{q}_{C7,0}$) เพื่อตัดความคลาดเคลื่อนจากการสวมใส่ (Mounting Diff):

q_i,cal(t) = q_i,origin⁻¹ ⊗ q_i,raw(t)   สำหรับ i ∈ {Left, Right, C7}

2. การตรวจสอบความเพี้ยนเทียบกับจุด Origin (Origin Drift & Coherence Check)

ระยะห่างและมุมสัมพัทธ์ระหว่างหูซ้ายกับหูขวาบนกะโหลกศีรษะต้องคงที่เทียบกับตอนเริ่มทดสอบ ($\Delta\mathbf{q}_{LR,0}$) พร้อมใช้ Gravity Vector ($\vec{g}$) ร่วมกับจุดอ้างอิง Origin หักล้างค่า Gyro Drift ($\epsilon_{\text{drift}}$):

q_Head,true(t) = SLERP( q_L,cal(t), q_R,cal(t), 0.5 ) ⊗ q_drift_comp(O_origin, g)⁻¹

3. การคำนวณระยะกระจัดจากจุด Origin ($\Delta\vec{P}_{\text{origin}}$) และมุม CVA

ΔP_Ear(t) = P_Ear(t) − P_Ear,origin  |  CVA(t) = atan2( Y_Ear(t) − Y_C7, Z_Ear(t) − Z_C7 )
WHY ORIGIN CHECK SOLVES DRIFT

เปรียบเทียบระบบทั่วไป vs ระบบเช็ค Origin ของเรา

ปัญหาหน้างาน IMU ทั่วไป (ไม่มี Origin Check) ระบบ C7-BioSync (Origin Reference)
1. มุมติดเซ็นเซอร์ที่หูแต่ละครั้งไม่เท่ากัน อ่านค่ามุมผิดพลาดทันที 5°–15° หักล้างเป็น 0.0° ทันทีด้วย Quaternion Tare เทียบจุด Origin
2. อาการ Gyro Drift สะสมเมื่อนั่งนานๆ พอกลับมานั่งตรง ค่ามุมยังเพี้ยนค้าง (เตือนมั่ว) เช็คเวกเตอร์แรงโน้มถ่วง + โซน Origin เพื่อดึงค่า Drift กลับศูนย์อัตโนมัติ
3. ผู้ใช้หมุนเก้าอี้ทำงานไปมา (Yaw Drift) แยกไม่ออกว่าหันคอหรือหมุนเก้าอี้ วัดมุมสัมพัทธ์กับโหนด C7 (ψ_Head − ψ_C7) หมุนเก้าอี้ได้อิสระ 360°
4. ขยับปากพูดคุย / เคี้ยวอาหาร เซ็นเซอร์ข้างเดียวสั่นจนค่า CVA แกว่ง ใช้ Bilateral SLERP หูซ้าย-ขวา กรองสัญญาณรบกวนออกทันที
06 // HARDWARE & EMBEDDED ARCHITECTURE

สถาปัตยกรรมฮาร์ดแวร์: BNO085 × 2 (ที่ใบหู) เชื่อมต่อสู่ ESP32 (ที่กระดูก C7)

ชิป BNO085 มีโปรเซสเซอร์ ARM Cortex-M0+ รันเฟิร์มแวร์ SH-2 ในตัว ให้ค่า Quaternion ที่ปราศจาก Drift โดยไม่ถูกรบกวนจากสนามแม่เหล็กของลำโพงหูฟังหรือโต๊ะทำงาน เราออกแบบทางเลือกการเชื่อมต่อไว้ 2 รูปแบบตามเฟสการพัฒนา:

OPTION A // แนะนำสำหรับ PROTOTYPE & รุ่นประหยัดพลังงาน

1. Wired Neckband Architecture (สายคล้องคอซิลิโคน)

  • ที่หูซ้ายและขวา: มีเฉพาะโมดูล BNO085 ขนาดจิ๋วในเคสเกี่ยวใบหู น้ำหนักเบาเพียง ~2–3 กรัม/ข้าง สวมใส่สบายตลอดวัน
  • การส่งข้อมูลลงมาที่ C7: เดินสายไฟซิลิโคนอ่อนนุ่มพิเศษเลียบสายคล้องคอลงมายัง ESP32-S3 ที่กระดูก C7 ผ่านบัส SPI (Multi-CS) หรือ Dual Hardware I2C (0x4A / 0x4B)
  • จุดเด่น: ใช้แบตเตอรี่ก้อนเดียวที่ C7 ชาร์จจุดเดียว อยู่ได้นาน 16–24 ชม. และซิงค์เวลาเซ็นเซอร์ตรงกันระดับไมโครวินาที
OPTION B // สำหรับรุ่น COMMERCIAL TRUE WIRELESS

2. True Wireless Ear-Clips (ไร้สายผ่าน ESP-NOW)

  • ที่หูซ้ายและขวา: BNO085 เชื่อมต่อกับไมโครคอนโทรลเลอร์จิ๋ว (เช่น Seeed XIAO ESP32-C3/S3) พร้อมแบตเตอรี่ LiPo จิ๋วในตัวเกี่ยวหู
  • การส่งข้อมูลลงมาที่ C7: ส่งแพ็กเกจ Quaternion ไร้สายแบบ Peer-to-Peer ด้วยโปรโตคอล ESP-NOW มายังโหนด ESP32 แม่ข่ายที่กระดูก C7
  • จุดเด่น: ไร้สาย 100% คล่องตัวสูง ความหน่วงต่ำกว่า < 4 มิลลิวินาที ไม่ต้องพึ่งพา Router Wi-Fi

💡 การแก้ปัญหาทางวิศวกรรมเชิงลึก (Key Engineering Secret)

เราหลีกเลี่ยงการใช้ I2C Multiplexer (TCA9548A) ร่วมกับ BNO085 บน ESP32 เนื่องจากปัญหา I2C Clock Stretching Bug แต่เลือกใช้สถาปัตยกรรม Hardware SPI พร้อมขา Interrupt (INT) และ Reset (RST) แยกอิสระ พร้อมปุ่มกด Hardware Origin Tare Button บนตัวกล่อง C7 เพื่อให้ผู้ใช้กดรีเซ็ตจุดอ้างอิงเริ่มต้นได้ทุกเมื่อ

07 // EXECUTION ROADMAP & PROTOTYPE BUDGET

แผนการดำเนินงาน 4 เฟส และโครงสร้างต้นทุนต้นแบบ (พร้อมเริ่มพัฒนาทันที)

PHASE 1 (เดือนที่ 1)

Hardware Bring-up

เชื่อมต่อ BNO085 ซ้าย-ขวา และโหนด ESP32 ที่ C7 ทดสอบการอ่านค่า Quaternion โหมด AR/VR Stabilized ความเสถียรต่อเนื่อง 24 ชม.

PHASE 2 (เดือนที่ 2)

Origin Calibration & Fusion

พัฒนาสมการ Origin Location Check, SLERP หูซ้าย-ขวา, การหักล้าง Drift อัตโนมัติ และอัลกอริทึมคำนวณมุม CVA

PHASE 3 (เดือนที่ 3)

3D Wearable & Haptic

พิมพ์ 3D เคสเกี่ยวใบหูและแผ่นยึด C7 ตามหลักสรีรศาสตร์ พร้อมระบบมอเตอร์สั่นเตือนอัจฉริยะ (Time-Window Biofeedback)

PHASE 4 (เดือนที่ 4)

Clinical Validation

เชื่อมต่อ Web/Mobile Dashboard ทดสอบความแม่นยำเทียบกับภาพถ่ายด้านข้าง (Photogrammetry) และสรุปผลวิจัย
